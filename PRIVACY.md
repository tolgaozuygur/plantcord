Privacy Policy for Plantcord

1. What Data We Collect
Message Content: The bot reads message content if the intent is granted. This is used to detect commands.
User Identifiers: The bot receives Discord user IDs and usernames to identify who triggered an interaction.
Server Data: The bot receives Guild and channel IDs to identify where interactions happen.

2. Why We Collect This Data
This data is tied directly to the bot's features. It is used strictly to read text commands and trigger the physical hardware.

3. Data Storage and Third Parties
Data is not sold or shared with any data brokers or third parties. 

4. User Rights & Contact
Users can request a copy of their data or have it deleted. For privacy inquiries or deletion requests, open an issue on the Plantcord GitHub repository or contact the developer directly.
